# Azriel Choerul Hakim — Portfolio

Personal portfolio landing page for **Azriel Choerul Hakim**.

## Direction

**Personal brand is not one discipline. It's a multiperspective.**

The site is intentionally built as a dependency-light static experience so it can be deployed directly to GitHub Pages.

### Included

- Editorial / art-directed layout
- Responsive desktop + mobile design
- Custom cursor + magnetic interactions
- Scroll progress
- Intersection-based reveals
- Discipline theme switching
- Animated marquee
- Reduced-motion support

## Run locally

Open `index.html` directly, or serve the folder with any static server.

## Deploy

Enable **GitHub Pages** from the repository settings and select the `main` branch as the source.
